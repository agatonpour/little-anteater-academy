# Private Soccer Training Platform

A web application for booking and managing private soccer training sessions.

The platform allows players to browse available training sessions, schedule private coaching, and manage their bookings through a simple web interface.

## Features

- Browse available private training sessions
- Book soccer training sessions
- Manage upcoming bookings
- Responsive user interface
- Modern web-based booking experience

## Tech Stack

- TypeScript
- React
- Vite
- Tailwind CSS
- shadcn/ui
